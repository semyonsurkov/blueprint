# blueprint

Локальная страница проекта, которая ставится командой внутрь репозитория. Своих данных у неё нет:
она показывает файлы проекта, поэтому синхронизировать два места не нужно.

Вкладки по умолчанию:

- **Архитектура**: схема в Excalidraw на весь экран (двигается и правится мышью, сохраняется в файл проекта сама)
  и кнопка «Документы» справа сверху, которая открывает markdown-документы боковой панелью (Esc закрывает).
- **Макеты**: iframe с html-каркасами.
- **MVP**: roadmap и идеи, отрисованные из markdown.

Тема светлая или тёмная: по системной настройке, кнопка справа в шапке переключает и запоминает выбор.

Нужны Python 3.9+ и доступ к `esm.sh` (React, Excalidraw 0.18.1 и marked грузятся оттуда
браузером, ничего не ставится через npm).

## Установка

```bash
./install.sh
```

Скрипт кладёт симлинк `blueprint` в `~/.local/bin`, поэтому обновление репозитория обновляет и CLI.

## Команды

| Команда | Что делает |
|---|---|
| `blueprint init` | в корне проекта создаёт `blueprint/` с кодом страницы и `blueprint.json`; существующий конфиг не перезаписывает |
| `blueprint update` | обновляет код страницы в проекте, конфиг не трогает |
| `blueprint` / `blueprint serve` | запускает сервер из корня проекта (ищет `blueprint/` вверх от текущей папки), `/` ведёт на страницу |

Страница коммитится вместе с проектом, поэтому у тех, у кого CLI не стоит, она всё равно запускается:
`python3 blueprint/serve.py`.

## blueprint.json

```json
{
  "title": "Мой проект",
  "port": 5190,
  "tabs": [
    { "id": "architecture", "title": "Архитектура", "type": "excalidraw",
      "file": "docs/architecture.excalidraw", "docs": ["docs/stack.md"] },
    { "id": "mockups", "title": "Макеты", "type": "frame", "src": "design/mockups/index.html" },
    { "id": "mvp", "title": "MVP", "type": "markdown", "docs": ["docs/roadmap.md", "IDEAS.md"] }
  ]
}
```

| Поле | Смысл |
|---|---|
| `title` | заголовок страницы |
| `port` | порт сервера, по умолчанию 5190 |
| `tabs[].id`, `title` | якорь в адресе и подпись вкладки |
| `type: "excalidraw"` | `file` — схема (создаётся при первом сохранении), `docs` — markdown под схемой |
| `type: "frame"` | `src` — html-файл, открывается в iframe |
| `type: "markdown"` | `docs` — список markdown-файлов подряд |
| элемент `docs` | строка-путь или `{ "path": "IDEAS.md", "collapsed": true }`, объект с `collapsed` делает документ выпадающим блоком: `true` свёрнут, `false` раскрыт по умолчанию |

Все пути считаются от корня проекта. Сервер слушает только `127.0.0.1`, отдаёт всё с
`Cache-Control: no-store`, не отдаёт `.git*` и `.env*` и пишет только в файлы `excalidraw`-вкладок из
конфига.

## Раскладка репозитория

```
bin/blueprint        CLI
page/                код страницы, копируется в проект
template/            blueprint.json по умолчанию
install.sh           симлинк в ~/.local/bin
```
