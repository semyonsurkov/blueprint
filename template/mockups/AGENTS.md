# Каркасы экранов

Каркас — серая структурная страница экрана без финального дизайна. Работай строго по шагам.

1. Найди экран в `screens.json` по полям `title` и `about`. Читай только его файл, остальные не открывай.
2. Новый экран создавай командой, а не руками:
   `blueprint new-screen OrderDetail --title "Заказ" --about "Что на экране одним предложением"`.
   Она создаёт файл и запись в `screens.json`.
3. Правь разметку классами из `wire.css`. Атрибут `style` только для размеров и позиции
   (`width`, `height`, `left`, `top`). Цвета, отступы, рамки и шрифты задаются классами.
4. Нужного класса нет — добавь одно правило в `wire.css` в раздел утилит с именем
   `свойство_значение`, например `.p_12_16 { padding: 12px 16px; }`.
5. Шапку и общие блоки не копируй: `<div data-wire="header"></div>`. Список блоков — в `wire.js`.
6. Одинаковые соседние элементы не дублируй: `data-repeat="3"` на первом.
   Иконки ставь атрибутом `data-icon="bell"` с именем иконки Lucide (lucide.dev/icons), svg вставит `wire.js`.
7. Текст служебный: `N`, `[кнопка]`, `ДД.ММ`. Данные не придумывай.
8. Отзывы лежат в `FEEDBACK.md`: открытые пункты `- [ ]` с путём к элементу от `.screen` экрана.
   Найди элемент по пути в файле экрана (путь `:scope` означает весь экран), исправь,
   отметь пункт `[x]`, текст пункта не меняй.
9. После каждой правки запускай `blueprint check` и исправляй всё, что он вывел.
   Работа закончена, только когда он пишет «макеты в порядке».
